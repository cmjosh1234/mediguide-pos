# MediGuide platform overview

`MediGuide-platform-overview.pptx` is the five-slide, editable presentation:

1. Overview: purpose, problem, approach and intended audience.
2. How it works: MoH website, MediGuide library, guideline search and reading.
3. How to access: public website, staff dashboard and Google Play links.
4. Demo: public website, mobile app, staff login and dashboard screenshots.
5. Next steps: sensitization, content expansion and proposed AI improvements.

Website screenshots were supplied by the platform owner. Mobile screenshots
use sample content rendered from the application. Speaker notes identify these
sources and explain the proposed next steps. Dashboard figures reflect the
supplied screenshot rather than a live usage report.

The deck was rendered for visual review and checked for five slides, package
integrity, layout geometry, font consistency and import compatibility. The three
access hyperlinks were verified in the presentation package.

Draft exports and private build files remain excluded from version control.
